# ETIP documentation

Beginner-friendly guides for installing, testing and integrating the
Enterprise Transformation Intelligence Platform (ETIP).

| Document | What it covers |
|---|---|
| **ETIP_Install_and_Test_Guide.docx** | Install (one-command and manual), a dashboard tour, and a feature-by-feature test checklist for every module. Start here. |
| **ETIP_Executive_Overview.pptx** | Buyer-facing executive deck — vision, capabilities, intelligence, cost control, governance and architecture. |
| **ETIP_Jira_Integration_Guide.docx** | End-to-end Jira connector setup and testing (two-way issue ↔ task sync), written for someone new to both tools. |
| **ETIP_Integration_Guides.docx** | The other integrations, each a click-by-click walkthrough: SSO (OIDC), outbound webhooks / Integration Hub, API keys, and CI/CD reporters. |
| **ETIP_Running_CICD_Guide.docx** | Beginner steps to run ETIP's own CI/CD pipeline — on your computer, and automatically on GitHub. |

All API steps use ETIP's built-in API page (Swagger) at `http://localhost:8000/docs`.
